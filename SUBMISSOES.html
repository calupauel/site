>SUBMISSÕES

SUBMISSÃO PARA A GALERIA

Para a galeria online do CALUPA, serão aceitos trabalhos de discentes e docentes do curso, além de trabalhos indicados por uma das duas categorias.

A galeria online tem a intenção de fazer circular entre os estudantes do próprio departamento a produção realizada por outras pessoas, possibilitando assim uma vasta referência do que tem sido produzido atualmente, ou do que já foi produzido.

Para o objetivo da galeria existir se concretizar, é necessário que seja compartilhado os trabalhos.

Portanto, para compartilhar algum trabalho, envie para o email do CALUPA, com o assunto "[SUBMISSÃO - GALERIA]", um link de uma pasta no Google Drive com os trabalhos + autore dos trabalhos + 3 palavras-chave para o trabalho.

SUBMISSÃO PARA ESCRITOS

A página de escritos do CALUPA talvez seja a página mais coletiva do CALUPA, é nela que ficarão os mais diversos textos, seja artigo, weblog, resenhas, poemas, poesias, etc...

Para a página de escritos do CALUPA, serão aceitos todos as formas de escrita

A página tem a intenção de tornar o ambiente online mais descontraído, uma forma de caderno coletivo onde todos os estudantes podem escrever ou indicar um texto feito por outra pessoa.

Para compartilhar algum escrito, envie para o email do CALUPA, com o assunto "[SUBMISSÃO - ESCRITOS]", um link de uma pasta no Google Drive com o texto em arquivo editável (.docx ou .odt) + autore do escrito + 3 palavras-chave para o escrito.
